# Contributing

Public Ledger is at the idea stage. Contributions are welcome through GitHub
issues and pull requests.

## How to contribute

1. Open an issue that describes the change before starting larger work.
2. Fork the repository and create a branch from `main`.
3. Keep each pull request to one focused change.
4. Run `npx markdownlint-cli2 "**/*.md"` and fix every error before you open
   the pull request.
5. Open a pull request against `main` that says what changed and why.

## Ground rules

- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Never commit secrets, credentials, or private or personal data.
- Back factual claims with a public source.
