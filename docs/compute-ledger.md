# Compute ledger

## Purpose

Log Cursor quota spent on Public Ledger. Cursor has no token-transfer feature.

## Ledger template

|Date|Contributor|Plan|Quota or credits used|Agent or task|Output link|Notes|
|---|---|---|---|---|---|---|
|YYYY-MM-DD|`<contributor>`|`<plan>`|`<quota>`|`<task>`|`<link>`|`<notes>`|

## Rules

- Log only quota actually spent on Public Ledger.
- Do not record credentials or account ids in the ledger.
